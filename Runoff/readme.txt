Inputs: names of candidates, number of voters, and the candidates listed by each voter in order of personal preference—from first to last place.
The program conducts an election using a ranked-choice voting system. Voters rank the candidates 
in order of preference. If no candidate secures an absolute majority (more than 50%), the candidate 
with the fewest votes is eliminated, and their votes are transferred to the next-ranked candidates. 
This process repeats until a winner is determined or a tie is reached.
